# 민첩한 일본어 하루! (すばやい一日)

해커톤 주제 **“민첩한 하루되세요”**를 일본어 학습과 결합한 브라우저 순발력 게임입니다. 아침부터 밤까지 이어지는 일상 행동의 뜻·한자·읽기를 제한 시간 안에 연결해 하루를 완주하세요.

## 게임 특징

- `뜻 → 일본어`, `일본어 → 뜻`, `漢字 → 읽기`, `읽기 → 漢字` 네 가지 문제 유형
- 4문제마다 3.2초 안에 답하는 돌발 퀵 미션과 점수 2배 보너스
- 3연속 정답부터 점수 배율이 오르는 `疾風(질풍) 모드`
- 시간대에 따라 변하는 화면과 하루를 달리는 진행 연출
- 플레이 후 정답률, 최고 콤보, 획득 한자 및 오답 복습 제공

## 플레이

- 공개 주소: <https://muffinhead03.github.io/LongArmMonkeyHyeGyoSKEAM/>
- 조작: `1`, `2`, `3` 키 또는 선택지 클릭·터치
- 목표: 12개의 하루 일과를 완료하기
- 규칙: 일반 문제 5.2초, 퀵 미션 3.2초, 기회 3개
- 점수: 정답을 빠르게 고르고 연속으로 맞힐수록 높은 점수 획득

## 로컬 실행

별도 설치나 빌드 과정이 없습니다. 저장소 루트에서 정적 서버를 실행한 뒤 브라우저로 접속합니다.

```bash
python3 -m http.server 8000
```

접속 주소: <http://localhost:8000>

## 파일 구조

- `index.html` — 시작, 플레이, 결과 화면
- `styles.css` — 반응형 UI와 게임 스타일
- `game.js` — 문제 데이터, 타이머, 점수, 생명, 결과 처리

## SKEAM 제출 체크리스트

- 브라우저 게임 주소: GitHub Pages 공개 주소 등록
- Windows 다운로드: 없음
- 등록 이미지: 가로 배너 필수, 권장 크기 `920 × 430`
- 스프레드시트: 개발자 이름, 게임 이름, SKEAM 닉네임, GitHub 저장소 링크, SKEAM 링크, 플레이 링크, 사용 AI/제작 도구 기록
- 공개 저장소에 API 키나 비밀번호를 추가하지 않기

이 프로젝트는 외부 API나 비밀 키를 사용하지 않습니다.
