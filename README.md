# 疾走! 민첩한 하루 — 一日ダッシュ

해커톤 주제 **“민첩한 하루되세요”**를 3레인 아케이드 회피 게임으로 만든 브라우저 게임입니다. 아침 7시부터 밤 11시까지 쏟아지는 일정과 돌발 상황을 피하고, 한자 아이템을 모아 40초의 하루를 완주하세요.

일본어는 문제를 푸는 학습 요소가 아니라 게임의 세계관, 장애물, 아이템과 시각 디자인에 사용합니다.

## 플레이

- 공개 주소: <https://muffinhead03.github.io/LongArmMonkeyHyeGyoSKEAM/>
- 키보드: `←`·`→` 또는 `A`·`D`로 길 이동, `1`·`2`·`3`으로 길 직접 선택
- 모바일: 화면 아래 왼쪽·오른쪽 버튼 또는 게임 화면의 좌우 영역 터치
- 목표: 장애물을 피하고 아침부터 밤까지 40초 완주
- 종료: 기회 3개를 모두 잃거나 밤에 도착하면 결과 표시

## 게임 시스템

- 시간이 흐를수록 장애물 속도와 출현 빈도 증가
- 후반에는 세 길 중 두 길을 동시에 막는 장애물 패턴 등장
- 연속 회피 콤보와 속도 기반 점수
- `疾風(질풍) 게이지`를 채우면 5초간 점수 2배
- 아침 `朝`, 낮 `昼`, 저녁 `夕`, 밤 `夜`의 시간대 변화
- 결과에서 진행도, 회피한 장애물, 최고 콤보와 아이템 획득량 표시

### 한자 아이템

| 아이템 | 효과 |
| --- | --- |
| `速` | 질풍 게이지 증가 |
| `守` | 다음 충돌 1회 방어 |
| `時` | 4초 동안 장애물 감속 |
| `福` | 보너스 점수 획득 |

장애물의 `会議`(회의), `締切`(마감), `渋滞`(정체), `雨`(비), `残業`(야근)은 뜻을 몰라도 색상과 형태만으로 피할 수 있습니다.

## 로컬 실행

별도 설치나 빌드 과정이 없습니다. 저장소 루트에서 정적 서버를 실행한 뒤 브라우저로 접속합니다.

```bash
python3 -m http.server 8000
```

접속 주소: <http://localhost:8000>

## 파일 구조

- `index.html` — 시작, 플레이, 결과 화면과 게임 캔버스
- `styles.css` — 반응형 아케이드 UI
- `game.js` — 게임 루프, 그리기, 충돌, 아이템과 점수 시스템

- 브라우저 게임 주소: GitHub Pages 공개 주소 등록

- 등록 이미지: 가로 배너 필수, 권장 크기 `920 × 430`
- 스프레드시트: 개발자 이름, 게임 이름, SKEAM 닉네임, GitHub 저장소 링크, SKEAM 링크, 플레이 링크, 사용 AI/제작 도구 기록
- 공개 저장소에 API 키나 비밀번호를 추가하지 않기

이 프로젝트는 외부 API나 비밀 키를 사용하지 않습니다.
